# Project Brief: EIS-4000

## Overview
Embedded firmware project targeting an ESP32 DevKit board using Arduino framework and PlatformIO.

## Current State
A basic UART↔USB serial forwarder bridging RS232 (Serial1, GPIO 19/20) to USB serial (Serial).

## Purpose
Requirements are still being defined. This project serves as a starting point for an EIS-4000 system.
